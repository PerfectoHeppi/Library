# Номын сан

Python ашиглан хийсэн номын сангийн бүртгэлийн жижиг төсөл.

## Төслийн зорилго

Номын сангийн номуудыг нэр, зохиолч, үнэ, ангиллын хамт файлд хадгалж, ном зээлэх, буцаах,
хайх, шинэ ном нэмэх зэрэг үйлдлүүдийг терминал дээрх цэсээр удирдах боломжтой болгох.

## Боломжууд

* Бүх ном харах
* Ангиллаар харах
* Нэр эсвэл зохиолчоор хайх
* Ном зээлд авах (номын сангаас гарч, зээлийн жагсаалтад орно)
* Ном буцаах (зээлээс буцааж номын санд орно)
* Зээлсэн номууд болон нийт дүн харах
* Шинэ ном нэмэх (ангиллыг гараар сонгоно)
* Баримт хадгалаад гарах
* Программаас гарах

## Өгөгдөл хадгалах

Номын сангийн одоо байгаа бүх ном `nomuud.txt` файлд хадгалагдана.
Өгөгдлийн бүтэц:

```
Ner,Zohiolch,Une

The Great Gatsby,F. Scott Fitzgerald,5000
A Brief History of Time,Stephen Hawking,8000
Charlotte's Web,E.B. White,3000
```

Ном зээлэхэд тухайн мөр `nomuud.txt`-с хасагдаж, `zeeldsen_nomuud.txt` файлд нэмэгддэг.
Ном буцахад эсрэгээр, мөр нь `zeeldsen_nomuud.txt`-с хасагдаж, `nomuud.txt` файлд буцаж бичигдэнэ.
Ангилал нь `("uran", "shinjleh", "huuhed")` гэсэн тогтмол tuple-с сонгогдоно.

## Ажиллуулах

Python суулгасан орчинд `nom_san.py` файлыг ажиллуулна.

```
python nom_san.py
```
